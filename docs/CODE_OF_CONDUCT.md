# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text at that link is the binding version; this page summarizes it and says how it applies here.

## Our pledge

We want Everything Spring Boot to be a welcoming place to learn and contribute — for beginners asking their first question and for experienced developers alike — regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Be kind and patient, especially with people who are new to Spring Boot or to open source.
- Give and accept constructive feedback on code and docs — critique the work, not the person.
- Assume good intent; ask before assuming.
- Take responsibility for mistakes and learn from them.

## Unacceptable behavior

- Harassment, insults, or derogatory comments, in public or private.
- Sexualized language or imagery, or unwelcome attention.
- Trolling, deliberately derailing discussions, or personal and political attacks.
- Publishing someone else's private information without explicit permission.
- Any other conduct that would reasonably be considered inappropriate in a professional setting.

## Scope

This applies in all project spaces — issues, pull requests, reviews, discussions — and when someone represents the project elsewhere.

## Reporting

## Enforcement

Maintainers may, depending on severity: give a private warning, ask for a public apology, temporarily restrict participation, or permanently ban someone from the project — following the enforcement guidelines of the Contributor Covenant 2.1.
